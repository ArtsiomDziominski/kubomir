# Kubomir

Бесконечный мир из блоков прямо в браузере. Один файл, без сборки и установки.

Добывайте дерево и камень, спускайтесь в пещеры за углём, железом, золотом и кристаллами, плавьте руду в печке, создавайте инструменты и броню, освещайте темноту факелами, храните добычу в сундуках и проспите ночь в кровати, пока снаружи бродят Тени. Мир сохраняется в браузере.

## Как запустить

Откройте `index.html` в браузере или [сайт на GitHub Pages](https://artsiomdziominski.github.io/kubomir/). Нужны клавиатура и мышь.

## Сохранение и обмен мирами

Мир сохраняется в браузере сам. В главном меню и в меню паузы есть кнопки:

- **Сохранить в файл** — скачивает мир файлом `kubomir-world-….json`: постройки, инвентарь, броню, сундуки, печки и кровать.
- **Загрузить из файла** — заменяет текущий мир миром из файла (игра сначала переспросит).

Файл можно отправить другу или перенести на другой компьютер. Каждый, кто загрузит его, получает свою копию мира.

## Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | ходьба, мышь — обзор |
| `Пробел` | прыжок, всплыть |
| `Shift` | бег (в полёте — вниз) |
| ЛКМ (держать) | добывать блок, ударить |
| ПКМ | поставить блок, съесть еду, надеть броню, открыть сундук или печку, лечь спать |
| `E` | инвентарь и крафт |
| `1`–`9`, колесо | выбор предмета |
| `F` | полёт вкл/выкл |
| `Esc` | пауза |

## Устройство

- Графика на [Three.js](https://threejs.org/) r128, подключается с cdnjs.
- Текстуры, предметы и мобы нарисованы кодом прямо в файле.
- Мир генерируется по зерну и хранится кусками 16×16×64; в сохранение попадают только изменения игрока.
